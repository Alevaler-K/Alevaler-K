### О себе
Документирую и валидирую REST API и интеграции, пишу Release Notes и инструкции для поддержки, проектирую BPMN- и Sequence-диаграммы. 

🎯 Моя главная цель — чтобы документацией пользовались, а не складывали её в архив. 

Работаю по методологии **Docs-as-Code**: документация живет в Git рядом с кодом и обновляется вместе с ним. Благодаря пониманию системного анализа и архитектуры сервисов (контракты API), моя документация всегда соответствует фактической реализации.

### 📈 Ключевые компетенции:
- **Документирование API:** описание эндпоинтов, параметров, JSON-схем, кодов ошибок (Swagger/OpenAPI).
- **Валидация контрактов:** проверка эндпоинтов в Swagger UI и Postman, сверка поведения сервисов.
- **Архитектура и логика:** визуализация решений в Sequence-диаграммах (PlantUML) и бизнес-процессах (BPMN).
- **Базы знаний:** структурирование пространств, внедрение единых шаблонов, написание Release Notes.
